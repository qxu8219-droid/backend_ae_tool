同次独立 SDK 测试使用真实 IsaacSim 6.2/PhysX、固定资产和原生回环 RTSP。左夹爪单关节分别输入合成 measured 超限、commanded 预警、无效前填、derived 四类 fixture，其余关节明确标为合成推算。独立 H.264 解码 248 帧全部通过像素 ID/CRC、唯一快照、质量、来源值和实际读回的核对；四类位图分别为 `[131072,0]`、`[0,131072]`、`[0,0]`、`[0,0]`，分别覆盖 42/57/57/92 帧。短窗口原始采集约 18.23fps；不是浏览器帧率或真实机器人数据结果。成功证据在会话停止、四个 worker 端口与自有网关退出核验后写入。

最终独立审查发现一项重要边界问题：前端把合法零跨度限位与未知限位混为一类，遮住快照超限标志。失败回归已复现；修复后将“有序有限上下限”和“可计算行程比例”分开，零行程保留正常/超限状态，比例为空。195 项前端单测和构建通过，无未处理审查项。后端源码在 764 项通过后没有因该前端修复改变。

边界测试覆盖非对称/单侧/零跨度/连续限位、容差、有限极端值、短峰、缺口、来源变化、多频率、包角展开、预算2及奇数、预算不足、原件隔离、旧帧/旧代次及后退重播。前端浏览器回归覆盖原有 Mock 交互和真实 API 返回503的边界，不冒充正式 SDK 前端联调。

所有源数据为本机生成的合成 fixture，未连接或修改真机/服务器。真机原始样本继续只读归档，夹爪和底盘语义仍待团队确认。已知限制：观测区间不推断亚采样穿越时刻；曲线预算不足会明确失败；即时告警候选仍需前端配对门槛；原生媒体运行限定已验证的 Linux/glibc 与固定 SDK。
